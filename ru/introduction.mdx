Doc Reviewer — настольное приложение, которое сканирует вашу техническую документацию — PDF, Word‑документы, файлы Markdown и веб‑страницы, находит в них инструкции и оценивает их по настраиваемому набору критериев с помощью LLM. Каждая инструкция получает цветовую оценку (зелёный, жёлтый, оранжевый или красный) и рекомендации для улучшения. Приложение теперь также предоставляет **резюме проверки документа**, давая быстрый обзор общей соответствия. Всё работает локально на вашем компьютере — без облачного аккаунта, без передачи данных, без подписки.

## Что делает Doc Reviewer

Когда вы загружаете документ, Doc Reviewer разбирает его на разделы и классифицирует каждый с помощью морфологического анализа. Разделы, содержащие инструкции — процедурные шаги, описания задач, последовательности действий — отправляются в LLM для оценки. LLM проверяет каждую инструкцию по критериям: стиль заголовка, структура шагов, полнота и описание результата, затем возвращает оценку и рекомендации. После завершения оценки генерируется **резюме уровня документа**, показывающее общее состояние документа и выделяющее самые критичные проблемные области.

Результаты отображаются цветом для быстрого анализа:

- **Зелёный** — инструкция соответствует всем критериям
- **Жёлтый** — незначительные недочёты, которые легко исправить
- **Оранжевый** — проблемы, влияющие на удобство использования
- **Красный** — критические недочёты, требующие немедленного внимания

Вы просматриваете результаты в дереве документа, отмечаете ложные срабатывания, экспортируете в XLS **или другие форматы** и сохраняете снимки оценки для сравнения качества между версиями документа.

## Для кого предназначен Doc Reviewer

Doc Reviewer создан для технических писателей в компаниях, которые разрабатывают продукты в области кибербезопасности, инструменты для разработчиков и сложное корпоративное ПО — продукты с большими наборами документации, где ручная проверка каждой инструкции непрактична. Если вы ведёте руководства по процедурам, пользовательские руководства или справку в формате веб‑страниц и хотите последовательно проверять качество инструкций перед выпуском, Doc Reviewer построен для этого рабочего процесса.

## Как работает Doc Reviewer

<Steps>
  <Step title="Установка и запуск">
    Скачайте `doc-reviewer.exe` и запустите его. Приложение стартует локальный сервер на `localhost:8000` и автоматически открывает интерфейс в браузере.
  </Step>
  <Step title="Подключение LLM">
    Перейдите в **Настройки → Модели** и добавьте провайдера LLM: OpenAI, Anthropic, Ollama или любой совместимый с OpenAI API. API‑ключ хранится локально в базе данных.
  </Step>
  <Step title="Создание проекта и загрузка документов">
    Создайте проект для продукта, затем загрузите файлы PDF, DOCX, Markdown или TXT — или вставьте URL, чтобы загрузить веб‑страницу через встроенный headless‑браузер.
  </Step>
  <Step title="Запуск оценки и просмотр результатов">
    Нажмите **Оценить**, чтобы проанализировать все обнаруженные разделы с инструкциями. Просмотрите цветовые оценки с рекомендациями, отметьте ложные срабатывания и экспортируйте результаты в XLS **или другие форматы**.
  </Step>
  <Step title="Просмотр резюме документа">
    После оценки откройте представление **Резюме**, чтобы увидеть общий балл соответствия и краткий список самых значимых проблем.
  </Step>
</Steps>
